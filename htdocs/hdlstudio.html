OIC Stage File NXSD Schema Generator (Piped Format)

How to use in Oracle Integration Cloud (OIC) Stage File Operation:

1. In OIC, add a Stage File action and choose Write File operation.
2. Select Sample NXSD Schema as the schema format type.
3. Download or copy this generated NXSD schema and upload it in the OIC wizard.
4. Map your source payload to this generated structure. OIC will output valid pipe-delimited (.dat) files separated by | and ended with ${eol} automatically.
